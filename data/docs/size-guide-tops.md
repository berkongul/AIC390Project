# Size guide: tops and jackets

## Chest measurements
Measure around the fullest part of your chest. S fits 88 to 94 cm, M fits 95 to 101 cm, L fits 102 to 108 cm, XL fits 109 to 116 cm and XXL fits 117 to 124 cm.

## Fit by product type
Hoodies have a relaxed fit, so choose the smaller size if you are between sizes. Shirts have a slim fit, so choose the larger size if you are between sizes. Jackets fit true to size with room for a layer underneath.
