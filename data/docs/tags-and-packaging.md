# Tags and packaging rules for returns

## Items with tags removed
If you removed the tags, we can still accept the return when the item is unworn and unwashed and the removed tags are included in the return parcel. Items returned without their tags are not accepted, unless they are defective.

## Shoe boxes
Return shoes in their original shoe box, placed inside a shipping bag or outer box. Do not put the shipping label or tape directly on the shoe box.

## Original packaging
Other items do not need their original plastic bag, but they must be packed so that they cannot get dirty or wet in transit.
