# W1.2 UC1 — Online Store Support Agent

## First customer and manual job
A small online clothing and shoe shop with a two-person support team answering repeated order-status, returns, shipping and sizing questions manually by email and chat. Clothing and shoes are where sizing, exchanges and damaged-item returns come up most, which matches our 25 test inputs (shoes, jackets, shirts, hoodies).

## User persona
A fictional customer-service representative who handles many routine requests and needs a reliable assistant that escalates unknown or sensitive cases.

## Five user stories
1. As a customer, I want to ask about an order so I can learn how to verify its status.
2. As a customer, I want to understand return rules so I know the next step.
3. As a customer, I want product details so I can decide whether an item suits me.
4. As a customer, I want to report damage so I can request a replacement review.
5. As a support agent, I want suspicious refund requests flagged so policy is followed.

## In scope
English customer messages; request categorization; safe policy-oriented responses; baseline LLM tests. Later: retrieval over shop policies, fake order/product data and sandbox return initiation.

## Out of scope
Real purchases, real customer records, live shipment tracking, real refunds, payments, and legal advice. The Week 1 baseline has no connected store database and must not invent order facts.
